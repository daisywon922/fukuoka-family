## 경비 기록
준비 단계 지출부터 여행 후 지출까지 합산합니다. 교통(항공 포함), 호텔, 보험, 투어, 식비, 쇼핑, 기타로 분류합니다. 원화·엔화는 환산 없이 별도로 합산합니다. 상단 KPI는 필터와 무관하게 전체 경비이고, 필터를 적용하면 선택 내역의 합계를 별도로 표시합니다.

실제 결제일과 관련 일정 날짜는 별개입니다. 일정에서 등록해도 결제일은 오늘로 기본 입력되며 바꿀 수 있습니다. 일정이 없으면 사전지출로 표시합니다. 날짜가 없는 기록은 정렬 방향과 관계없이 맨 아래에 둡니다. 같은 결제일 내에서는 기존 저장 순서를 유지합니다.

전달받은 호텔 결제액 677,181원은 최초 가계부 전환 시 한 번 등록합니다. 결제일과 결제자는 알려지지 않아 미입력으로 두었습니다. 수정 화면에서 입력할 수 있습니다. 항공 후보 금액은 경비에 넣지 않았습니다. 기존 지출은 유지하고 항목이 없는 기록은 기타로 분류합니다. 기존 날짜는 결제일로 이어받으므로 필요하면 수정하세요.

통계는 모달에서 날짜별 / 항목별 막대 차트로 표시하며 원화·엔화를 전환합니다. 모든 지출 기준으로 계산하고 결제일 미입력 금액은 별도 묶음으로 표시합니다. 삭제 직후 10초간 되돌릴 수 있습니다.

## 환산 KPI·필터·통계
총 경비는 원화 지출 + 엔화 지출 × (100엔당 원화 / 100)로 환산합니다. 기본 환율은 사용자가 지정한 100엔=890원이며 환율 변경 버튼에서 입력합니다. 환율은 기록과 함께 보관되며 원금은 유지됩니다. 현재 자동 환율 조회는 연결하지 않았습니다.

항목 필터는 전체/교통/숙박/보험/투어/식비/쇼핑/기타 체크박스로 복수 선택합니다. 기존 호텔 항목은 숙박으로 이어받습니다. 날짜별 통계는 결제일 기준 여행 첫째 날~넷째 날과 기타로 구분합니다. 도넛의 구간과 항목 목록을 누르면 별도 모달에 원본 지출 내역을 표시합니다. 전체 환산액과 원화만/엔화만 통계를 선택할 수 있습니다. 데모 총액 2,937,473원, 100엔=1,000원 변경 시 3,035,681원 계산과 320px 화면을 확인했습니다.

## 버튼 배치 정리
항목 필터는 왼쪽 드롭다운, 정렬은 오른쪽 최신순/오래된순 텍스트 버튼으로 구분합니다. 통계 버튼은 총 경비 카드 오른쪽 위에 배치했습니다. 통계의 날짜별/항목별 탭은 고정 2열이고 통화 선택은 다음 줄로 분리했습니다. 모든 닫기를 X 아이콘으로 통일하고 모달 주요 행동은 오른쪽 끝으로 배치합니다. 헤더 메뉴와 패널도 오른쪽에 위치합니다. 연결 일정 없는 지출에서는 사전지출 문구를 숨깁니다.

## 지출 카드 상세
카드에서 결제자 표시는 숨기고, 관련 일정이 없으면 사전지출을 표시합니다. 카드 터치 또는 ••• → 상세정보로 결제일·결제자·항목·금액·연결 일정·엔화 환산액을 조회합니다. 상세의 수정 버튼과 카드의 더보기는 독립적으로 동작합니다.

## 금액 묶음과 결제수단
총 경비 (N건) 제목으로 변경했습니다. KPI 엔화 바로 아래 환산액을 두고 하단에는 기준 환율과 명확한 환율 변경 버튼을 둡니다. 지출 상세도 엔화 → 환산 원화 → 기준 환율 순으로 묶습니다.

결제수단은 현금/카드이며 기존 기록의 결제수단이 없으면 현금으로 채웁니다. 등록·수정에서 선택하고 목록의 보조 정보, 상세, 내보내기, 백업과 결제수단별 통계에 반영합니다. 현금잔액 기능은 없습니다. 기존 데모 기록은 현금으로 유지하며 혼합 집계는 저장하지 않는 별도 데이터로 검증합니다.

## 일정·지출 공통 데이터 모델
일정은 시작할 때 한 번만 공통 형식으로 변환합니다. id, schemaVersion, title(장소명), activity(활동), time, notes(메모), map(지도), address, source, bookingId를 기준으로 카드·상세·경로·관련 지출이 같은 데이터를 조회합니다. 기존 displayName/place/detail은 변환 후 제외합니다. schemaVersion=1로 저장된 편집 데이터는 예전 표시용 기본값으로 덮어쓰지 않습니다. 일정 화면의 + 일정 추가와 일정 상세의 수정·삭제로 일반 일정을 관리할 수 있습니다. 장소명·날짜·시간·활동·메모를 편집하며, 날짜 변경 시 해당 날짜로 이동하고 시간순으로 다시 정렬합니다. 항공·호텔 예약은 이 편집 대상에서 제외합니다. 변경분(eventOverrides)과 삭제 ID(deletedEventIds)는 기기 저장 및 백업에 포함됩니다. 일정 ID는 유지하므로 연결 지출도 유지되며, 일정 삭제 시 지출 기록은 삭제하지 않습니다. 삭제 직후에는 되돌리기가 가능합니다. 일정 상세의 지출 항목은 기존 지출 상세정보 모달로 연결됩니다.

결제수단은 JPY 지출만 cash/card를 저장합니다. 기존 KRW 지출의 paymentMethod는 제거하고, JPY에서 미지정이면 현금을 적용합니다. 등록·수정·복원은 공통 정규화를 사용합니다. 목록에는 결제수단을 표시하지 않으며 JPY 상세에서만 확인합니다. 결제수단 통계도 JPY만 집계합니다. 통화 표시는 ¥로 통일했습니다.

일정 상세의 지출내역은 한 묶음 안에서만 구분선을 사용합니다. 일정 카드는 반복되는 지출 문구 없이 합계만 표시하고, 카드와 상세는 같은 activity와 지출 합계를 조회합니다.


예약현황: 호텔·항공·투어·보험·통신 예약은 공통 데이터에서 목록과 상세를 렌더링합니다. 상세의 수정에서 각 항목과 완료/미완료를 편집하며, 상태는 목록 칩에만 표시합니다. 결제금액·결제자·결제처를 공통으로 제공합니다. 변경분과 삭제 ID는 기기 저장 및 전체 백업에 포함됩니다. 예약 삭제는 일정이나 지출을 삭제하지 않으며 직후 되돌릴 수 있습니다. 예약 금액 수정은 별도 지출 기록을 자동 변경하지 않습니다.
