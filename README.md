# 후쿠오카 여행

2027년 3월 10–13일 가족여행용 모바일 웹앱입니다.

배포: https://daisywon922.github.io/fukuoka-family/

## 가족 사용

처음에는 별도로 받은 가족 초대 링크로 접속하고 🌼 / 🐻 / 👸🏻 프로필을 선택합니다. iPhone은 Safari, Android는 Chrome에서 링크를 열고 홈 화면에 추가합니다. 초대 링크는 접근 권한이므로 공개 저장소나 외부에 올리지 않습니다. 홈 화면 추가는 초대 링크로 접속한 화면에서 진행합니다. 기존 아이콘이 연결되지 않으면 초대 링크에서 다시 추가합니다.

일정·예약·지출·여행 메모·구성원·환율·공통 및 개인 체크리스트는 Supabase 공용 저장소에 저장합니다. 개인 체크리스트는 프로필별이고 메모는 모두 볼 수 있습니다. 선택한 프로필과 자동 인증 세션은 기기에 기억합니다. 관리자 표시는 가족 간 편의 기능이며 강제 신원 확인은 아닙니다.

새 기기에서는 초대 링크로 연결합니다. 초대 링크 재접속과 GitHub 재배포는 가족 데이터를 초기화하지 않습니다. 연결 대기 중에는 전송하지 못한 기록이 기기에 있으므로 브라우저 데이터를 지우기 전에 공유 완료를 확인하세요.

## 개발 및 배포

정적 파일을 수정해 main 브랜치에 배포합니다. 별도 빌드는 없습니다. 새 버전 화면은 새로고침/재실행 후 적용되며 데이터는 서버 기록을 유지합니다. 푸시 알림·오프라인 앱 설치용 서비스워커는 아직 포함하지 않습니다.

공개 연결 정보: `shared-config.js`. 비밀번호, service_role/secret 키, 실제 초대 코드는 코드에 넣지 않습니다.

설정과 데이터 동작: [SHARED-SETUP.md](SHARED-SETUP.md)

검증:

```sh
node tests/shared-merge.cjs
node tests/shared-storage.cjs
node tests/shared-canonical.cjs
```
