## 가족 사용

처음에는 별도로 받은 가족 초대 링크로 접속하고 🌼 / 🐻 / 👸🏻 프로필을 선택합니다. iPhone은 Safari, Android는 Chrome에서 링크를 열고 홈 화면에 추가합니다. 초대 링크는 접근 권한이므로 공개 저장소나 외부에 올리지 않습니다. 홈 화면 추가는 초대 링크로 접속한 화면에서 진행합니다. 기존 아이콘이 연결되지 않으면 초대 링크에서 다시 추가합니다.

일정·예약·지출·여행 메모·구성원·환율·공통 및 개인 체크리스트는 Supabase 공용 저장소에 저장합니다. 개인 체크리스트는 프로필별이고 메모는 모두 볼 수 있습니다. 선택한 프로필과 자동 인증 세션은 기기에 기억합니다. 관리자 표시는 가족 간 편의 기능이며 강제 신원 확인은 아닙니다.

새 기기에서는 초대 링크로 연결합니다. 초대 링크 재접속과 GitHub 재배포는 가족 데이터를 초기화하지 않습니다. 연결 대기 중에는 전송하지 못한 기록이 기기에 있으므로 브라우저 데이터를 지우기 전에 공유 완료를 확인하세요.

## 개발 및 배포

정적 파일을 수정해 main 브랜치에 배포합니다. 별도 빌드는 없습니다. 새 버전 화면은 새로고침/재실행 후 적용되며 데이터는 서버 기록을 유지합니다. 푸시 알림·오프라인 앱 설치용 서비스워커는 아직 포함하지 않습니다.

공개 연결 정보: `shared-config.js`. 비밀번호, service_role/secret 키, 실제 초대 코드는 코드에 넣지 않습니다.

설정과 데이터 동작: [SHARED-SETUP.md](SHARED-SETUP.md)

검증:

```sh
node tests/shared-merge.cjs
node tests/shared-storage.cjs
node tests/shared-canonical.cjs
node tests/places.cjs
```

## 1.3.0 · 장소 목록 및 입력 개선

일정 / 장소 / 예약 / 지출 순서입니다. 장소는 카테고리·장소명·지도 검색값·메모와 즐겨찾기를 저장합니다. 즐겨찾기는 상단 우선 정렬하며 전체/카테고리별 필터를 제공합니다. 일정 추가의 장소명은 저장 목록 선택과 직접 입력을 합친 콤보박스입니다. 목록에서 명시적으로 선택했을 때만 장소명과 지도 검색값을 복사합니다. 입력한 이름이 저장된 장소와 같아도 자동 연결하지 않습니다. 이후 양쪽의 수정·삭제는 서로 영향을 주지 않습니다.

`http://127.0.0.1:8766/?preview=real-release`는 별도 기기 저장 공간에서만 작동하는 미리보기이며 Supabase를 연결하지 않습니다. 예시 장소는 미리보기에만 제공합니다. 모든 입력 모달의 빨간 별표는 실제 required 상태와 연동합니다.

## 업데이트 이력 관리

`releases.js`의 `APP_RELEASES`를 최신순으로 관리합니다. 과거 이력은 기능 단위로 묶은 표시용 버전이며 Git 커밋 횟수와 무관합니다. 이후에는 배포마다 버전·날짜·실제 변경 내용을 추가합니다. 검토 중 항목은 `pending: true`로 두고, 실제 배포할 때 `false`로 바꾸면서 날짜를 확정합니다. 정보 상단의 버전과 이력은 같은 데이터로 표시합니다. 여행 데이터와 달리 이력은 코드에서 관리합니다.

## 1.4.0 · 개인 체크리스트 두 단계

개인 항목에 `children` 배열을 선택적으로 저장합니다. 자식은 한 단계만 허용하며 상위 그룹 이동 시 함께 이동합니다. 부모 체크는 자식 전체에 적용되고, 일부 완료는 부분 체크로 표시합니다. 진행률은 자식이 있는 그룹의 자식과 단독 항목만 세어 중복 집계하지 않습니다. 수정 모달은 깊은 복사로 열어 저장 전 편집이 실제 기록에 섞이지 않습니다. 공통 체크리스트는 기존 한 단계 방식입니다.

기본 준비물은 필수품·세안도구·화장품·옷으로 구성합니다. 최초 적용 시 원예은은 23개, 안인숙은 22개, 오성섭은 16개이며, 전용 준비물은 이름을 기준으로 구분합니다. 기존 체크 및 사용자 추가 항목을 보존하며 기본값은 한 번만 합칩니다. 이후 사용자가 기본 항목을 수정·삭제해도 자동 복원하지 않습니다.

로컬 예시: `http://127.0.0.1:8766/?preview=real-release&section=personal`. 실제 공용 저장소와 연결하지 않습니다. `previews/`의 독립 HTML은 검토용이며 Git에 포함하지 않습니다.

검증: `node tests/checklist-tree.cjs`, `node tests/checklist-defaults.cjs`.
